# Reto 2 - Lista de Tareas

## Descripción

Este proyecto consiste en una aplicación web de lista de tareas desarrollada con HTML, CSS y JavaScript.

La aplicación permite agregar tareas, marcarlas como completadas y eliminarlas. También utiliza almacenamiento local del navegador para conservar las tareas.
